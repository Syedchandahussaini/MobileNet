# 📱 MobileNet Image Classification & Object Detection

## 📌 Project Overview
This project implements Image Classification and Object Detection using the MobileNet deep learning model with TensorFlow and OpenCV.

The model is capable of detecting and classifying objects from images efficiently with high speed and lightweight architecture.

---

## 🎯 Objectives
- Perform image classification using MobileNet
- Detect and classify objects from images
- Use pre-trained deep learning models from TensorFlow Hub
- Implement real-time object recognition workflow

---

## 🧠 Model Used
### MobileNet
MobileNet is a lightweight Convolutional Neural Network (CNN) architecture designed for:
- Fast image classification
- Mobile and embedded vision applications
- Low computational cost
- Real-time performance
